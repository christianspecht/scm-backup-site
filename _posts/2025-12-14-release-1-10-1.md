[SCM Backup 1.10.1](https://github.com/christianspecht/scm-backup/releases/tag/1.10.1) is available.

- Added [support for Bitbucket API tokens](https://docs.scm-backup.org/en/latest/config-bitbucket.html#authentication)  
    *([contributed](https://github.com/christianspecht/scm-backup/pull/85) by [Julien Quartier](https://github.com/BriskoCube))*

---

Once again, a bugfix for a breaking change in Bitbucket: App passwords *(which SCM Backup used for authentication)* will be [replaced by API tokens](https://www.atlassian.com/blog/bitbucket/bitbucket-cloud-transitions-to-api-tokens-enhancing-security-with-app-password-deprecation):

**It's no longer possible to create new app passwords, and all existing app passwords will stop working June 9, 2026. So everybody who is using SCM Backup to backup private Bitbucket repos has to switch to API tokens until then.**
